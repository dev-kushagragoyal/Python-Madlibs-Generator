# Python-Madlibs-Generator
A text-based, interactive Mad Libs game built using Python. It prompts the user to select a storyline and inputs various parts of speech to dynamically generate a unique, humorous story. Demonstrates basic console I/O, conditional structures, and string concatenation.

# 🚀 How to Run
1. Run the script using Python: `python main.py`
2. Select Option 1 for a funny food-themed story, or Option 2 for an inspiring, personalized future success story!
3. Fill in the prompts (nouns, verbs, adjectives) and read your dynamic output.

# ⚠️ Disclaimer
The stories generated by this program are completely random, fictional, and intended purely for entertainment purposes. The output depends entirely on the words entered by the user.
